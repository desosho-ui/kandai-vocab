# VOCABMATE — 関大 語彙トレーナー

関西大学の4クラス（1LS / 1RW / 2RW / 4RW）向けの語彙学習アプリです。
全3,452語、各クラス Unit 1〜8 を収録しています。

## このリポジトリの中身

| ファイル | 用途 |
|---|---|
| `index.html` | **学生用アプリ**。テスト配布QRコードの宛先になります |
| `robots.txt` | 検索エンジンにこのサイトを登録させないための設定 |

公開URL: `https://desosho-ui.github.io/kandai-vocab/`

> **教員用アプリは公開しません。**
> `teacher.html` は先生のMac内（`26年度関大/Vocab List/teacher.html`）に置き、
> そこからテスト作成・QR配布・成績確認を行います。
> 学生に配るのは上の公開URL（QRコード）だけです。

## 教員用アプリの設定（初回のみ）

⚙️ 初期設定 に3つ入れます。

1. **学生が開くページのURL** — 上の公開URL
2. **Apps Script のURL** — 下の手順で作る `.../exec` のURL
3. **先生のメールアドレス** — 学生が送信に失敗したときの提出先

### Apps Script（成績の自動集計）

**設定済みです。** 提出された成績は Google スプレッドシート「**VOCABMATE 成績**」に自動で記録されます。
最初から作り直す場合の手順は次のとおりです。

1. Google スプレッドシートを新規作成
2. 教員用アプリ → ⚙️ 初期設定 → ▸ 自動集計の設定のしかた → 📋 コードをコピー
3. スプレッドシート → 拡張機能 → Apps Script → 中身を全部消して貼り付け → 保存
4. デプロイ → 新しいデプロイ → ウェブアプリ → 実行ユーザー「自分」／アクセス「全員」→ デプロイ
5. `.../exec` で終わるURLを ⚙️ 初期設定 に貼る

> **「🔑 鍵を作り直す」は普段押さないでください。**
> 押すと Apps Script のコードを貼り直して再デプロイする必要があります。

> **コードを更新するときの注意**
> 2回目以降は「デプロイを管理 → ✏️ → バージョン『新バージョン』」を使ってください。
> 「新しいデプロイ」を選ぶとURLが変わり、学生の提出が届かなくなります。

## 大事なこと

- **教員用アプリは必ず同じブラウザ（Chrome）で開いてください。** これだけが唯一のルールです。
  テスト設定・集計用の鍵・取り込んだ成績はブラウザのローカル保存領域に入っており、
  この保存領域は「ファイルの場所」ではなく「ブラウザ」に紐づいています。

  | 操作 | 設定は引き継がれるか |
  |---|---|
  | 別のフォルダへ移動する | ✅ 問題なし |
  | デスクトップやUSBメモリに置く | ✅ 問題なし |
  | ファイル名を変更する | ✅ 問題なし |
  | Chrome や Mac を再起動する | ✅ 問題なし |
  | Safari など別のブラウザで開く | ❌ 別扱いになり、設定が見えません |
  | 別のパソコンで開く | ❌ 別扱いになり、設定が見えません |
- テストを作ったら **「🔄 いま編集中のテストをQRに反映」** を押してから配布してください。押さないとQRは古い内容のままです
- 学生の端末は**提出のときだけ**オンラインが必要です。学習自体はオフラインで動きます
- 読み上げはブラウザの音声合成を使います。収録音声や外部サーバーへの通信はありません

## 更新のしかた

語彙リストを差し替えるときは `index.html` を新しいものに置き換えて push してください。教員用ファイルはMac内のものを差し替えます。
学生の学習記録はそれぞれの端末に残るので消えません。
